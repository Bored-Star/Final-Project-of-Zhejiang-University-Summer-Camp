这个代码架构是根据我的研究报告和论文初稿来建立的，可以印证我的建模和算法。
代码架构如下：
dfig_harmonic_inversion/
├── requirements.txt          # 环境依赖（你提供的包补齐完善）
├── main.py                   # 主运行入口：批量生成合成数据 + 消融对比实验
├── config/
│   └── params.py             # 全局风机、电网、仿真固定参数统一管理
├── model/
│   ├── __init__.py
│   ├── aerodynamic.py        # 气动可微模型（风切变+塔影+tanh平滑）
│   ├── mechanical.py         # 双质量块可微轴系ODE模型（diffrax）
│   ├── electrical.py         # DFIG间谐波+辅助观测变量模型
│   └── full_forward.py      # 三层级联端到端可微正向映射 F(p)
├── inversion/
│   ├── __init__.py
│   ├── loss_func.py          # 带Tikhonov正则最小二乘损失函数
│   ├── adjoint_grad.py       # 伴随状态法梯度求解
│   └── hybrid_opt.py         # 贝叶斯+L-BFGS混合优化算法
├── dataset/
│   ├── __init__.py
│   └── data_generator.py     # 批量生成带噪声合成数据集
├── utils/
│   ├── __init__.py
│   ├── plot_tools.py         # 绘图：误差柱状、收敛曲线、频谱图
│   └── math_helper.py        # JAX数学辅助函数、边界平滑工具
└── output/                   # 自动生成图片、仿真数据npy文件
    ├── figs/
    └── data/
